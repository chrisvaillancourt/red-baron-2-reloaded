# Friction log

What made work slower than it needed to be: missing tools, confusing structure, wrong or
missing instructions, flaky commands. Every final report ends with a Friction section;
the lead logs each item here with a disposition.

- **Dispositions:** **Do** (concrete fix, not yet made), **Defer** (worth doing, with the
  trigger), **Done** (fixed, with commit), **Skip** (not worth it, with reason).
- **Promote lessons.** A shared lesson becomes an `AGENTS.md` rule; harness mechanics go in
  `docs/HARNESSES.md`. The row then points at the rule.
- **Prune when logging a wave.** Delete Done and Skip rows; git history keeps them.
